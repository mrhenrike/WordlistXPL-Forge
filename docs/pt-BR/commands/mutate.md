# `mutate`

Mutacoes de uma senha existente (case/leet/afixo).

Novo: `--titlecase` tambem semeia uma variante CamelCase por token da base (ex.: `nerd_trilha` -> `Nerd_Trilha`), padrao humano comum que as variacoes de caixa padrao nao geram. Para encadear afixos compostos (data + especial de uma vez) sobre uma wordlist inteira, use o comando `affix`.
